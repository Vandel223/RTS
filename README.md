# RTS - Real-Time Systems

Project for the Real-Time Systems course. The repository has two parts: a
bare-metal embedded application on a PIC microcontroller (Part 1) and a
FreeRTOS-based application on an mbed LPC1768 board (Part 2).


## Repository structure

  README.md
  Part1/
    tstTC74LCD.X/            MPLAB X project (PIC16F18875)
      main.c                 Application logic
      EEPROM/                Read/write helpers for parameters and records
      I2C/                   I2C helper routines
      LCD/                   LCD driver
      TC74/                  TC74 temperature sensor driver
      mcc_generated_files/   Code generated by MPLAB Code Configurator
      nbproject/             MPLAB X project configuration
  Part2/

      C12832/                Graphic LCD driver

      MMA7660/               MMA7660 accelerometer driver
      freertos-cm3/          FreeRTOS kernel and Cortex-M3 port


## Part 1 - PIC16F18875 clock, thermometer and luminosity monitor

A real-time clock with temperature and luminosity monitoring, alarms and
persistent records.

Hardware
  - Microcontroller: PIC16F18875
  - Temperature sensor: TC74 (I2C)
  - Display: 16x2 LCD
  - Luminosity: potentiometer on the ADC (RA0), reduced to 2 bits (levels 0-3)
  - Alarm output: PWM6 (buzzer)
  - LEDs: LED_C (RA7, clock heartbeat), LED_T (RA5, temperature alarm),
    LED_L (RA4, luminosity alarm)
  - Buttons: SW1 (RB4), SW2 (RC5)

Features
  - Clock (hours:minutes:seconds) driven by a 1 second timer (TMR1).
  - Temperature and luminosity sampled every PMON seconds.
  - Temperature alarm when temperature >= ALAT.
  - Luminosity alarm when luminosity level <= ALAL.
  - Clock alarm when the clock matches ALAH:ALAM:ALAS.
  - Each alarm type uses a different PWM duty cycle, and the sound stops
    after TALA seconds.
  - Maximum and minimum temperature and luminosity records (with the time of
    occurrence) stored in EEPROM.
  - Parameters and clock time stored in EEPROM and restored at start-up
    (defaults are used if the EEPROM is empty).
  - Button debouncing using TMR3 and TMR5 (100 ms).

Buttons
  - SW1: clears active alarms (normal mode).
  - SW2: cycles the display through the current values, the temperature
    records and the luminosity records. The display returns to the current
    values after TINA seconds.

Parameters (default values)
  PMON  monitoring period in seconds          5
  TALA  alarm duration in seconds             3
  TINA  inactivity time in seconds            10
  ALAF  alarms enabled (1) / disabled (0)     1
  ALAH  alarm clock hours                     12
  ALAM  alarm clock minutes                   0
  ALAS  alarm clock seconds                   0
  ALAT  temperature alarm threshold           20
  ALAL  luminosity alarm threshold            2
  CLKH  clock hours                           0
  CLKM  clock minutes                         0

Status
  The configuration mode is declared in the code but not yet implemented.

Build
  1. Open Part1/tstTC74LCD.X in MPLAB X IDE.
  2. Use the XC8 compiler (the project was generated with XC8 3.10) and the
     PIC16F1xxxx_DFP device pack.
  3. Build and program the board.

  The files in mcc_generated_files/ are generated by MPLAB Code Configurator
  (tstTC74LCD.mc3) and should be changed through MCC rather than by hand.


## Part 2 - FreeRTOS on mbed (LPC1768)

A multitasking application built on the FreeRTOS kernel (Cortex-M3 port, RVDS
toolchain, heap_1 memory scheme) running on an mbed LPC1768 board.

Components
  - main.cpp, comando.cpp, monitor.cpp: application tasks
  - RTC.cpp / RTC.h: real-time clock handling
  - msg.h: message definitions shared between tasks
  - C12832: graphic LCD driver
  - LM75B: temperature sensor driver
  - MMA7660: accelerometer driver
  - freertos-cm3: FreeRTOS kernel sources and FreeRTOSConfig.h

Build
  The project uses mbed OS tooling (see .mbed and mbed.bld) with the LPC1768
  target and the ARM toolchain. It can be imported and compiled with mbed CLI
  or the mbed online compiler.


## Notes

  - Part 1 targets MPLAB X on macOS, but any platform supported by MPLAB X
    and XC8 should work.
  - Generated and IDE-specific files (nbproject/private, build outputs) are
    not needed to build and can be ignored or regenerated.
